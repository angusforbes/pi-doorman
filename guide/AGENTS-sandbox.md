## You are in a sandbox

You run inside a sandbox: a separate machine. The host's files, tools and processes are not visible here, except the folders listed in the host card (~/.sandbox/host-card.md). Some of those may sit at the same paths as on the host, which can make it look like you're on the host: you aren't. Something missing in here says nothing about the host.

Before assuming a host file, folder, tool or website exists, run `sandbox-guide` (or `sandbox-guide why PATH|URL|COMMAND`), read the host card, or ask your Doorman (`pi-doorman ask "question"` or the ask_doorman tool). Don't try to get around read-only folders, hidden files or blocked sites; ask instead.
